## What this release is
CapCraft's editor and native engine, unchanged, with NexVora identity: new name, application ID `com.nexvora.motionstudio`, original icon and logo, dark cyan/purple design system, redesigned Home Edit tab, editor top bar, export settings and export result, media picker header, settings, About, dialogs and sheets, and a restyled timeline, dock and panel frame.

## Known limitations (important)
- **Never compiled or run.** There is no APK in this delivery. See `TEST_REPORT.md`.
- The timeline, preview and the Adjust/Presets tabs and most of the ~40 editing panels still have their original layouts with the new palette; Effects, Filters and every panel using the shared tabs/tiles/search got new components.
- No landscape layout (portrait-only app). No tablet or accessibility testing.
- `SOURCE_URL` in the About screen still points to the upstream CapCraft repo; publish your modified source and change it before distributing (AGPL).
- Release workflow still names APKs `capcraft-android-*`; sign with your own keystore.
